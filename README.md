# Greed Project

A simple starter website built with plain HTML, CSS and JavaScript.

## Files

- `index.html`: page content and structure
- `styles.css`: colors, layout and dark mode
- `script.js`: dark mode toggle and footer year

## Run it

Open `index.html` in any web browser. No installs or build step needed.

## Edit it

- Change text and sections in `index.html`.
- Change colors at the top of `styles.css` (the `--accent` color is the main brand color).
